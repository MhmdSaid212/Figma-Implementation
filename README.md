# Figma Implementation

In this project, I was given a Figma design and had to replicate it as a website (front-end only).

## 🛠️ Built With
- React
- CSS (custom, no frameworks)

## 📁 Project Structure
- `components/` - Reusable React components
- `styling/` - Component-specific CSS files
- `images/` - Static images
- `icons/` - SVG icons
